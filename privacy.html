秘書（Hermes）｜最終更新: 2026-10-18

本ページは、個人が自身の業務・研究の補助のために運用する非公開の個人用ツール「秘書（Hermes）」（以下「本ツール」）における、Google ユーザーデータの取り扱いを説明するものです。本ツールは一般公開されておらず、利用者は本人 1 名のみです。

1. 取得する情報

本ツールは、利用者本人の同意のもと、以下の Google アカウントのデータにアクセスします。

  • Gmail: メールの本文・件名・送信者（アシスタントによる下書き作成・内容確認のため）
  • Google カレンダー: 予定の読み取りと、利用者本人の予定の登録
  • Google ドライブ: 利用者が指定したファイルの読み取り

2. 利用目的

取得した情報は、利用者本人のスケジュール管理、メール対応の下書き作成、記録の整理など、本人の業務補助の目的にのみ使用します。

3. 第三者提供

取得した情報を第三者に販売・提供・共有することはありません。広告やマーケティングの目的でも使用しません。

4. 保存と安全管理

認証情報（トークン）は利用者の管理する端末およびサーバー内にのみ保存します。Google ユーザーデータは、本人が指定したクラウド／端末の範囲内で処理され、運用に必要な範囲を超えて保持しません。

5. データの削除

利用者は、Google アカウントの「セキュリティ」→「サードパーティ製アプリ」から本ツールのアクセス権を取り消すことで、いつでも連携を解除できます。取り消し後、本ツールは当該データにアクセスできません。

6. Google API の限定使用

本ツールによる Google API から取得した情報の使用は、Google API サービスのユーザーデータに関するポリシー（Limited Use 要件を含む）に準拠します。

7. お問い合わせ
